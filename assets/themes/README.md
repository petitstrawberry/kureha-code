# Bundled palette attribution

These TOML files are Kureha Code mappings of the following palettes. They are
not complete imports of upstream editor plugins or their syntax rules.

| Preset | Source | License |
| --- | --- | --- |
| Dracula | [Dracula theme](https://github.com/dracula/dracula-theme) | MIT, see dracula.LICENSE |
| Monokai | [VS Code Monokai](https://github.com/microsoft/vscode/blob/main/extensions/theme-monokai/themes/monokai-color-theme.json), based on the original Monokai palette | MIT, see monokai.LICENSE |
| Nord | [Nord](https://github.com/nordtheme/nord) | MIT, see nord.LICENSE |
| Solarized Dark / Light | [Solarized](https://github.com/altercation/solarized) | MIT, see solarized.LICENSE |
| Gruvbox Dark | [Gruvbox](https://github.com/morhetz/gruvbox) | MIT/X11 as declared in the upstream README; palette values only |
| Tokyo Night | [Tokyo Night](https://github.com/folke/tokyonight.nvim) | Apache-2.0, see tokyo-night.LICENSE |

Palette values were checked against upstream sources on 2026-11-09. Original
names identify their respective projects; these mappings are maintained here.
